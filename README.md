# Фрил-Бух

Простая бухгалтерия для фрилансера: клиенты, почасовка, оплаты и долги.
Без регистрации, без сервера и без сборки — всё работает в браузере и хранится
на вашем устройстве.

**Сайт:** https://skamsystem.github.io/fril-buh/

## Что умеет

- **Клиенты** — имя, ставка за час, телефон, email и заметка.
- **Работы** — дата, часы или время начала/окончания, категория и описание.
  Ставка сохраняется в момент записи, поэтому старые работы не меняются
  задним числом при изменении ставки клиента.
- **Оплаты** — сумма, дата, способ (наличные, карта, перевод, онлайн) и
  комментарий.
- **Баланс** — оплачено минус заработано. Отрицательный баланс — долг
  клиента, положительный — аванс.
- **Обзор** — заработано, оплачено, долг и часы за месяц, прошлый месяц или
  всё время; список должников и последние работы.
- **Поиск, фильтры, периоды, сортировка** по клиентам, работам и оплатам.
- **Корзина** — удалённые записи можно вернуть.
- **Бэкап** — выгрузка и импорт JSON, экспорт работ и оплат в CSV.
- **PIN-код** — по желанию, с автоблокировкой через 5 минут.
- **Темы** — светлая, тёмная или как в системе.
- **Валюта** — ₽, $, €, ₸, ₾, ₴, Br.
- **Офлайн-режим** и установка на телефон как обычное приложение (PWA).

## Установка на телефон

1. Откройте https://skamsystem.github.io/fril-buh/.
2. **iPhone (Safari):** «Поделиться» → «На экран „Домой“».
3. **Android (Chrome):** меню ⋮ → «Установить приложение».

После установки приложение открывается на весь экран и работает без интернета.

## Где хранятся данные

Данные лежат только на устройстве: в IndexedDB, с резервной копией в
`localStorage`. На сервер ничего не отправляется. У каждого устройства своя
база — чтобы перенести данные, скачайте бэкап в настройках и импортируйте его
на другом устройстве.

> **Важно:** PIN — номинальная защита от случайного взгляда. Он не шифрует
> данные и не спасает при доступе к браузеру. Регулярно делайте бэкап.

## Локальный запуск

Двойной клик по `start.command` — откроется http://localhost:4174.
Или вручную:

```bash
python3 -m http.server 4174
```

## Структура

```
index.html            разметка и модальные окна
styles.css            оформление, светлая и тёмная темы
js/db.js              IndexedDB + запасной localStorage
js/app.js             логика: расчёты, экраны, формы, PIN, бэкапы
manifest.webmanifest  параметры установки на телефон
sw.js                 офлайн-кэш (frilbuh-v2)
icons/                иконки приложения
start.command         локальный сервер для Mac
```

## Технологии

Vanilla HTML/CSS/JS, без сборки и зависимостей. Service worker кэширует
оболочку: сначала сеть, затем кэш. При изменении CSS/JS поднимайте версию
`CACHE` в `sw.js`, иначе установленные копии останутся на старых файлах.

## Публикация
